## 📌 Overview

**EcoFlux-RL** is a Reinforcement Learning-based system designed to optimize **urban traffic signal control** while considering both **traffic efficiency and environmental impact**.

Traditional traffic signal systems mainly focus on reducing vehicle waiting time and congestion. However, prolonged vehicle queues and idling can increase fuel consumption and **CO₂ emissions**.

EcoFlux-RL addresses this problem by using a **PPO (Proximal Policy Optimization) Reinforcement Learning agent** that learns traffic-signal control decisions inside a simulated urban environment.

The project combines:

- 🚗 Urban Traffic Simulation
- 🚦 Intelligent Traffic Signal Control
- 🤖 Reinforcement Learning
- 🌱 Carbon/CO₂ Awareness
- ⚡ Real-Time Backend Communication
- 🗺️ Interactive Traffic Visualization
